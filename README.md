Project Description :

This project is a CPU Scheduling Simulator that compares
SRTF and Round Robin scheduling algorithms using GUI and Gantt Charts.


Requirements :

Python 3.12.9
Tkinter (used for building the graphical user interface)
Matplotlib (used for generating the Gantt charts)


Run Steps :

1. Open project in VS Code or PyCharm
2. Install required libraries
3. Run main_window.py in GUI file
